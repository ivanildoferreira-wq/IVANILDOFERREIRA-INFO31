# Aula 02 — Vite + Vue + Componentização

Projeto prático de componentização com Vue 3 e Vite.

## Setup

```sh
npm ci
```

## Desenvolvimento

```sh
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173) no navegador.

## Build

```sh
npm run build
```

## Preview

```sh
npm run preview
```

## Estrutura

- `src/App.vue` — Componente raiz
- `src/components/` — Componentes filhos (AppHeader, ProjectCard, AppFooter)
- `src/main.js` — Entrada da aplicação
- `src/style.css` — Estilos globais
- `docs/App-monolitico.vue` — Referência: versão monolítica
